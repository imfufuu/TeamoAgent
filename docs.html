用户协议

使用本应用即视为接受本协议全部内容。

本应用目前为 β（测试）版本，按「现状」提供。AI 生成内容可能不准确、不完整或过时，不构成专业建议，重要决策请自行核实。

01软件性质

  • 纯前端静态网页：对话、沙箱、文件均在你自己的浏览器中运行；模型推理经你配置的 API Key 通过 TeamoRouter 网关完成。
  • 不做任何明示或默示的适销性、准确性、不中断或无错误的保证。

02账号与密钥

  • 无账号体系。API Key 仅保存在本地浏览器，请自行妥善保管；泄露导致的后果由使用者承担。
  • 请勿将 Key 交予他人使用，或用于本协议禁止的用途。

03使用规范

  • 不得利用本应用生成、传播法律法规禁止的内容，包括但不限于未成年人色情、暴力犯罪、毒品制贩、反社会内容等。
  • 内置本地内容审核（β）对高风险内容执行拦截；审核为辅助手段，不构成免除使用者责任的依据，最终责任由使用者承担。
  • 不得滥用、攻击或试图破坏本应用、网关或上游模型服务的可用性。

04责任限制与变更

  • 在法律允许的最大范围内，作者对使用本应用产生的任何直接或间接损失不承担责任。
  • 本协议可能随版本更新调整，变更后在本页面发布即生效；继续使用视为接受变更。

服务条款

服务范围、可用性与内容边界。

01服务说明

  • 提供网页端 AI 智能体服务：多模型对话、思考过程展示、代码沙箱执行、文件读写、图像生成、联网检索、子智能体委派等。
  • 模型推理由 TeamoRouter 网关（api.teamorouter.com）路由至 Anthropic、OpenAI、Google、DeepSeek、智谱、月之暗面、xAI 等第三方模型服务商；各服务商另有其服务条款，请一并遵守。

02可用性

  • β 服务，无可用性承诺（SLA）；网关、上游模型或静态托管中断时部分或全部功能可能不可用。
  • 部分能力（联网中继、离线缓存）依赖浏览器环境，功能可用性以页面内实际提示为准。

03内容审核

  • 图片审核在本机浏览器内由本地模型（NudeNet / NSFWJS）执行，文本审核由本地策略层与语义模型执行；命中高风险阈值的图片以「失败即拦截」（fail-closed）处理。
  • 被拦截内容不进入沙箱与模型上下文；审核逻辑与阈值可能随版本调整。

04沙箱与文件

  • 代码沙箱在浏览器本地执行生成的代码并维护虚拟文件系统；请勿在沙箱内放置敏感凭据或唯一副本数据。
  • 沙箱文件、会话记录保存在本地浏览器存储中，清除浏览器数据将一并清除。

隐私政策

数据最少化、本地优先。

01保存在你浏览器本地的数据

  • 会话记录、设置、API Key、长效记忆、沙箱文件与附件：保存于浏览器的 localStorage 与 IndexedDB，不会上传到作者或任何统计服务。
  • 清除方式：应用内「清空会话」、浏览器清除站点数据，或 /system 通道的 /cache clear（清离线缓存）。

02发送给第三方的数据

  • 你发送的消息与附件（含图片）会经 TeamoRouter 网关（api.teamorouter.com）转发给你所选模型的服务商用于生成回复；这是对话功能的必然传输。
  • API Key 仅作为网关鉴权凭证发送，不用于其他目的。
  • 内容审核模型（NudeNet / NSFWJS / Toxicity 等）在本地浏览器运行，审核过程不向作者上传任何内容；仅审核通过的图片才会随消息发往网关。

03不收集的信息

  • 不含统计分析、埋点、广告追踪或指纹采集；不请求通知、地理位置等敏感权限。
  • 作者不运营任何后端数据库，无法也无需存储你的对话内容。

04离线缓存与联系

  • Service Worker 将模型、审核资产与厂商图标缓存在本地（Cache Storage），用于加速与离线可用；缓存仅含静态资源，不含你的任何个人数据。
  • 本政策自发布之日起生效；如有疑问请联系 lks.tan.cn@gmail.com。
