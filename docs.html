隐私政策

数据最少化、本地优先。

版本：V1.4（2026-09-30 修订）生效日期：2026-09-30

01我们如何处理数据（总览）

  • 本应用遵循「本地优先」：你的会话记录、设置、API Key、长效记忆、沙箱文件与附件保存于浏览器的 localStorage 与 IndexedDB，不会上传到作者或任何统计服务。
  • 作者不运营任何后端数据库，无法也无需存储或查看你的对话内容。

02本地存储技术说明

  • localStorage：轻量状态（设置、模型选择、会话骨架、API Key）。
  • IndexedDB：重数据（附件图片、沙箱生成图等大文件），与应用状态分开存放。
  • Cache Storage（Service Worker）：模型、审核资产与厂商图标的离线缓存，仅含静态资源，不含个人数据；可用 /system 通道 /cache clear 或浏览器设置清除。
  • 本应用不使用 Cookie 进行追踪，也不设置广告或分析类 Cookie。

03发送给第三方的数据

  • 你发送的消息与附件（含图片）会经 TeamoRouter 网关（api.teamorouter.com）转发给你所选模型的服务商用于生成回复；这是对话功能的必然传输。
  • API Key 仅作为网关鉴权凭证发送，不用于其他目的。
  • 内容审核模型（NudeNet / NSFWJS / Toxicity 等）在本地浏览器运行，审核过程不向作者上传任何内容；仅审核通过的图片才会随消息发往网关。
  • 第三方服务商对所接收数据的处理受其各自隐私政策约束。

04我们不收集的信息

  • 不含统计分析、埋点、广告追踪、指纹采集或行为画像；不请求通知、地理位置、通讯录等敏感权限。
  • 不主动采集你的设备信息、IP 或使用时长；静态托管（GitHub Pages）侧的基础访问日志由其按自身政策处理，与作者无关。

05数据保留与安全

  • 本地数据保留至你主动清除（应用内「清空会话 / 清空记录」、浏览器清除站点数据、或卸载浏览器）。
  • API Key 仅在本地存储并仅向网关发送；请勿在共享设备上保存 Key。

06儿童隐私

  • 本应用面向一般用户，不面向 14 周岁以下儿童单独提供服务；如发现在无监护人同意下收集了儿童个人信息（本地存储），可通过下方联系方式要求清除。
