少而准的工具，而不是仪表盘。

模型只调用真实存在的能力：浏览器内的代码与文件、网关生图与识图、本地编解码。没有的功能不会假装有。

沙箱

JavaScript Worker、Pyodide（可装第三方库）与远程 C++20。超时可杀，stdout / 返回值可捕获，改动写回工作区。

工作区

读写、追加、局部替换、复制删除、正则搜索、文本差分、JSON 整理。ZIP 打包解压上限 128 条，容量 120 MB。

图像

文生图与改图走 generate_image；识图统一 analyze_image。对话通道保持纯文本，结果写入沙箱 outputs/。

思考

Off → Ultra 七档。过程可展开，耗时可见。Max 与 Ultra 才允许委派；Ultra 另加自检与多专家复核。

本地工作台

正则、哈希、编解码、Unicode、差分、JSON，不必为这些开沙箱。关沙箱时代码执行不可用，文件工具仍在。

带走结果

侧栏按卡片列出容量与文件树。打包 ZIP、下载单文件。有本地中继时还能对真实 git 仓库操作。

思考档不是装饰。

Off 不发思考参数。High 不能委派。Ultra 在 Max 之上再加自检与多专家交叉复核。Claude 5 / GPT / Gemini 常常只在服务端思考、不返回正文。

为什么选我们？

不是更大的仪表盘，而是浏览器里就能交差的智能体：工具真跑、文件能带走、没有的能力不会装有。

打开即用

没有客户端、没有账号墙。填入自己的 TeamoRouter Key，选模型就能开始。会话、附件、沙箱都在这一个标签页里。

本地密钥

密钥只写在本机浏览器，请求直发网关。我们不提供账号系统，也就没有「把你的对话存在我们服务器」这一环。

工具会真跑

JS / Python / C++ 在沙箱执行，超时可杀。工作区 120 MB，ZIP 打包带走。生图、识图、本地编解码都是真实调用，不是聊天窗里口算。

不装有的能力

没有模型原生网页搜索就写没有。识图走专用工具，git 只在本地中继。介绍页和对话页说同一份产品，方便核对。

不会假装有的能力。

介绍页和对话页说的是同一份产品。下面这些限制写进提示词，模型不会用「已经搜过」来搪塞。

  • 没有模型原生网页搜索。有本地中继时用 fetch_url 抓具体网址；GitHub Pages 上该开关不可用。
  • 对话模型看不见图片。识图必须走 analyze_image（deepseek-v4-flash-vision-exp），返回全文。
  • run_git 只在本机工作区白名单命令下执行，不经 shell。没有中继就没有真实 git。
Key 存在哪里？

TeamoRouter 的 API Key 只写在本机浏览器。我们不提供账号系统，刷新后对话、附件与沙箱仍在 localStorage / 会话存储里。

和对话页是不是两套产品？

不是。介绍页只负责说明，对话在 app.html。沙箱、工作区、生图、思考档、本地工具与这里写的一致。

为什么有些模型不能识图？

对话通道一律纯文本，避免各模型 multimodal 行为不一致。需要看图时由工具调用专用识图模型，结果落盘后可以再读。
